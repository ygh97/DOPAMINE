# 도파민 센터 (Dopamine Center)

내 돈 말고 가상자산으로 주식·코인 단타의 도파민만 느끼는 실시간 다인원 모의투자 게임.
$100,000로 시작해 20배면 **졸업**, 100배면 **전설**. 시즌은 8시간(게임 1년)이고, 모든 시세·뉴스는 게임용 허구다.

- 실제 시총 상위 미국 주식 20종 + 코인 5종 + 가상 신흥주 10종 (가상 시세)
- 진짜 호가창: 모든 주문이 호가창에서 체결된다. 시장가(수수료 0.05%)·지정가(체결 수수료 0), 미체결 관리, 최근 체결
- 현물·선물(롱·숏, 최대 10배, 격리 증거금, 강제 청산·스탑·익절), 가짜 뉴스로 움직이는 시세 엔진
- 실시간 랭킹·명예의 전당·채팅·귓속말·포트폴리오 훔쳐보기·티배깅

## 빠른 시작 (개발)

```bash
npm install
npm run dev:server   # http://127.0.0.1:4810
npm run dev:web      # http://127.0.0.1:5173  (화면, /api는 4810으로 프록시)
npm run dev:test     # 봇 100명 + 세력과 같이 해 보는 테스트 서버 http://127.0.0.1:5183 (DB 따로)
npm run check        # 전체 확인 (테스트·타입·시뮬레이션·브라우저 종단 테스트, 약 2분)
```

Node 24 이상. 빌드 없이 TypeScript를 바로 실행한다.

## 구조

apps/web          Vue 3 화면 (KLineChart)
tools/            시뮬레이션, 종단 테스트, 배포 스크립트(deploy.ps1)
docs/             지난 설계·작업 기록
